# ccnp-git-practice

Practice repository for **AUTOCOR 350-901, 2.1 Git** on ccnp-automation.hitech007.ai
(chapter 2.1 Git Basics, section 4: fork a public repository and keep your copy up to date).

1. Fork it on github.com, clone your fork, add this repository as `upstream`.
2. Change `NOTES.md` in your fork, commit, push.
3. Bring newer upstream work into your fork: `git fetch upstream` then `git merge upstream/updates`
   (normally `upstream/main`). The branch `updates` holds those newer commits.
